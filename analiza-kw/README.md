# Analiza księgi wieczystej — zakup działek

**Cel:** ocena prawna stanu księgi wieczystej przed zakupem działek nr **775/65, 41, 31, 43, 32, 33**.

**Data rozpoczęcia:** 2026-06-30

## Zakres analizy (czego szukamy)

1. **Służebności** — wszystkie ustanowione (gruntowe, osobiste, przesyłu): treść,
   uprawniony, obciążona/władnąca nieruchomość, dział KW (zwykle Dział III).
2. **Wady / wzmianki ujawnione w księdze** — ostrzeżenia, wzmianki o wnioskach,
   roszczenia, niezgodności stanu prawnego, zaznaczenia w Dziale III i IV.
3. **Aktualni właściciele** (Dział II) — kto, na jakiej podstawie, jakie udziały.
4. **Prawomocność / ciąg tytułów własności** — przejście własności przez:
   - **spadkobranie** (postanowienia o stwierdzeniu nabycia spadku / akty poświadczenia dziedziczenia),
   - **podziały** nieruchomości i działek (które działki z których powstały),
   - czy łańcuch tytułów jest zamknięty i prawomocny.
5. **Hipoteki i inne obciążenia** (Dział IV).

## Struktura katalogu

- `zrodla/`   — surowe materiały: wydruk księgi (PDF), dokumenty spadkowe, mapy, decyzje podziałowe.
- `notatki/`  — robocze notatki, ekstrakcja danych z działów I–IV.
- `wyniki/`   — finalny raport z analizą i rekomendacjami.

## CZEGO POTRZEBUJĘ OD CIEBIE (blokuje pracę)

Portal EKW jest chroniony captchą i sesją — nie da się pobrać księgi z samego linku
(zwraca 403). Wgraj do katalogu `zrodla/` jedną z poniższych rzeczy:

- **Najlepiej:** PDF wydruku zwykłego/zupełnego księgi wieczystej (cała treść działów I-O, I-Sp, II, III, IV).
  - *Wydruk ZUPEŁNY* jest istotny dla oceny ciągu spadków i podziałów (pokazuje także wpisy wykreślone).
- Ewentualnie: numer KW (format `XXXX/NNNNNNNN/N`) — ale i tak będę potrzebował treści, bo numeru samego nie wystarczy.
- Jeśli masz: postanowienia spadkowe, akty poświadczenia dziedziczenia, decyzje podziałowe, wypisy z rejestru gruntów.

Możesz też wkleić treść księgi bezpośrednio w czacie.
